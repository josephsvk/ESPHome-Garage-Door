ESPHome-Garage-Door

jednoducha inštalacia minimalna sprava stači len spravne zapojit GPIO nastavit secret.yml a skopirovat esphome-sample.yml do esphome .

feartures :
    pripojenie pomocu wg k homeassistantu držat inštalaciu esp v jednej sieti .
    robustne ovladanie garažovej alebo inej brany .
    možnost roznych senzorov navyše .

instalation on esphome: 
    HomeAssistant > 
    ESPHomeBuilder > 
    + Create device > 
    Advanced set up options > 
    Empty Configuration > 
    Set name you device > 
    paste esphome-sample.yml > 
    save > 
    install > 
    use you prefer > 
    have fun and test
